# Support

Thanks for using Spark AI NLP research software. These repositories are research prototypes maintained by a small team, so support is best-effort.

## Where to ask

| Need | Where |
|---|---|
| Bug in code, tests, or docs | Open a **Bug report** issue in the repository |
| Question about methods, definitions, or results | Open a **Research question** issue |
| A claim looks unsupported or mis-tagged | Open a **Claim correction** issue |
| Security vulnerability | Follow [SECURITY.md](SECURITY.md) (private report, not a public issue) |
| Collaboration or research partnership | Contact options at [sparkainlpx.xyz](https://sparkainlpx.xyz) |

Please search existing issues first and include the repository, commit or tag, your OS, and the exact command you ran.

## Accessibility

Spark AI NLP is disability-led. If you need documentation in another format (plain-text, larger print, screen-reader-friendly tables, French), or need more time to respond in a discussion, say so in an issue or through [sparkainlpx.xyz](https://sparkainlpx.xyz). We will do our best to accommodate.

## What we cannot provide

- Guarantees of fitness for any hardware, clinical, or safety-critical use
- Private consulting through GitHub issues
- Support for forks that change the evidence tags or remove the scope statements
