# sparkainlp-x/.github

Default community health files for public repositories owned by [sparkainlp-x](https://github.com/sparkainlp-x) (Spark AI NLP).

GitHub applies these files to any public repository in this account that does not ship its own copy:

| File | Purpose |
|---|---|
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to propose changes; evidence-tag rules for claims |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability (GitHub private vulnerability reporting) |
| [SUPPORT.md](SUPPORT.md) | Where to ask questions, and accessibility requests |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE) | Bug report, research question, claim correction |
| [.github/pull_request_template.md](.github/pull_request_template.md) | PR checklist with evidence tags |

## Evidence tags

Every number in these repositories carries one of these tags:

| Tag | Meaning |
|---|---|
| **SYNTHETIC** | Produced by our own simulation or tests on generated inputs |
| **REPORTED** | Measured by us; host, tools, and raw data linked; not independently reproduced |
| **TARGET** | A design goal; not yet achieved or measured |
| **UNRUN** | Tooling or scripts exist; the run has not been performed |

All repositories are research prototypes. None is a medical device, a certified control system, or a quantum-hardware result.
